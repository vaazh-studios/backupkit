# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be kind, be specific, assume good faith, and keep disagreements about the code. Harassment of any kind is not tolerated. Report problems to founder@vaazhstudios.com; reports are handled privately and within a week.
